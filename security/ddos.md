# DDoS 攻击专题分析

## 一、什么是 DDoS

Distributed Denial of Service（分布式拒绝服务攻击）。攻击者利用多台被控制设备（僵尸网络）同时向目标发送海量请求，耗尽带宽/CPU/内存等资源，使其无法服务正常用户。

### 攻击类型

| 类型 | 攻击目标 | 典型手段 |
|------|----------|----------|
| 流量型 | 耗尽带宽 | UDP Flood、DNS Amplification |
| 协议型 | 耗尽网络设备资源 | SYN Flood、Ping of Death |
| 应用层 | 耗尽应用服务器 | HTTP Flood、Slowloris、CC 攻击 |

## 二、攻击者动机

| 动机 | 说明 |
|------|------|
| 经济勒索 | 威胁不付款就打瘫服务，电商/游戏/金融最怕 |
| 商业竞争 | 竞对在关键节点（大促、新版本）雇佣攻击者 |
| 政治/意识形态 | 表达立场、制造舆论压力 |
| 转移注意力 | DDoS 制造混乱时从另一方向数据窃取/入侵 |
| 炫耀/娱乐 | 脚本小子证明技术、获取名声 |
| 复仇 | 被辞退员工、不满客户、个人恩怨 |
| DDoS 即服务 | 暗网租用攻击（Stresser/Booter），几十到几百美元一次 |

## 三、发动攻击的条件

**僵尸网络（Botnet）**：恶意软件感染（木马/漏洞传播）将普通设备变肉鸡；IoT 设备（摄像头/路由器）是主要来源（如 Mirai 蠕虫）；也可直接租用。

**放大技术**：利用 DNS/NTP/Memcached 协议特性，发送伪造源地址小请求，让服务器向目标返回几十上百倍流量。

**攻击者层级**：

| 层级 | 特征 | 能力 |
|------|------|------|
| 脚本小子 | 只会用现成 GUI 工具（LOIC） | 效果有限，易暴露 |
| 熟练玩家 | 能搭建 C2、批量抓肉鸡 | 可造成实质性威胁 |
| 专业黑产 | 高级规避手段，组合拳打法 | 对多数企业构成严重威胁 |

**资金**：租用几十到几百美元一次，僵尸网络按时长或流量计费。

## 四、防御策略

### 核心难点

肉鸡和正常用户无法从请求层面区分——真实设备、真实浏览器、真实 IP，所有技术指纹可伪造（JA3、浏览器指纹、JS 执行等）。

### 有效策略

**1. 经济成本锚定（PoW / 微支付）**
每个请求算数学难题（几百毫秒 CPU），真实用户无感，攻击者 100 万请求需 100 万核秒计算资源。

**2. 身份信誉系统**
技术特征可伪造，但行为和历史不可伪造。登录用户的账号信誉（注册时间、消费记录），未登录用户通过 Privacy Pass / Device Attestation 建立长期匿名信誉。将防御从「单次请求」层面提升到「身份/会话」层面。

**3. 容量碾压**
Anycast + 全球 CDN + TB 级清洗能力（Cloudflare/Akamai）。

**4. 业务层异常检测**
不检测请求特征，检测业务结果。攻击脚本再真，业务产出是空的（不会下订单、搜索不同关键词、页面停留时间无变化）。

### 分层防御体系

```
正常 + 攻击流量
  → Anycast/BGP: 分散到全球节点
  → 流量清洗: SYN Proxy、协议校验
  → 速率限制 + 行为分析
  → WAF + Challenge
  → 正常用户到达服务器
```

## 五、DDoS 勒索的经济学

### 赎金市场存在的悖论

买 Cloudflare 等专业防御比付赎金更理性，但勒索市场仍然存在：

- **不是所有服务都能套 CDN**：游戏（UDP, 实时性）、VoIP/SIP、金融/工控协议
- **信息不对称 + 恐慌**：中小企业主不懂安全，看到网站打不开就付钱
- **赎金定价低于防御年费**：一次性 3000 美元 vs 每月 5000 美元
- **攻击可绕过 CDN 打源站**：通过历史 DNS 记录、SSL 证书日志、扫描 IPv4 找到真实 IP
- **可持续施压**：一直打而不一定打瘫，运维团队持续高压

### 暴利区间为何没被抹平

- 攻击能力和勒索能力是两种资源：攻击是商品（几十美元），勒索是手艺（需要付款通道、威慑力、情报）
- 风险溢价：勒索涉及资金流转和 Extortion 罪名，量刑远高于纯粹 DDoS
- 目标群体天然过滤：最强企业（扛得住）和最弱的（没钱付）都不付，中间地带恰好有钱但不懂行的企业才付，且复购率接近零

### 本质

靠法律阴影和信息差维持的套利闭环，不是真正的有效市场。

## 六、勒索资金的匿名化

### 核心思路

不追求「不可追踪」，而让追踪成本大于追回金额。

### 匿名链路

```
受害者 → BTC → 混币器（打散交易链路）
  → 多轮混合 + 跨链桥
  → Monero（环签名+隐形地址+RingCT，数学上无法追溯）
```

**关键节点**：
- **混币器**：多人的币池化后随机输出到新地址
- **Monero**：环签名 + 隐形地址 + RingCT，金额/发送方/接收方全模糊
- **跨链桥**：BTC → Monero → 另一条链，跨链后失去连续性

### 为何追不回来

| 因素 | 说明 |
|------|------|
| 管辖权分割 | 链上地址 → IP 在俄/朝 → 无引渡 → 执法到此为止 |
| 混币器规模效应 | 成千上万人混在一起，比对所有人不可行 |
| 执法成本 > 追回金额 | 跨国司法协作 + 数据分析 → 几万刀的案子不值得 |
| 去 KYC 出金 | P2P 市场现金买 Monero，不走 Coinbase |

### 现金洗白

- **分散出金**：拆小额到几十上百张卡（收购的身份信息），不同时间/ATM 取现
- **OTC 伪装**：用网店刷单/贸易假单伪造资金来源，赚 3-5% 汇率差
- **现金密集型行业**：餐厅/KTV——天然收现金，黑钱混进营业流水
- **买实物变现**：珠宝/金条/奢侈品 → 二手卖掉，折价即洗白成本

### 产业链模块化

勒索者（得币）→ 折价 70% 卖给洗钱服务商 → 洗钱商有完整出金渠道赚差价。从赎金到最终干净钱打 40-50% 折扣，但几十美元的攻击撬动几万块赎金，利润仍可观。

## 七、总结

1. **技术层**：靠「识别攻击流量」是死路，肉鸡和正常用户无法从特征区分
2. **防御层**：有效策略不是区分而是提高攻击成本——PoW、身份信誉、容量碾压
3. **经济层**：攻击商品化但暴利仍存，勒索变现需另一种竞争力
4. **金融层**：匿名链路本质不是不可追踪，而是让追踪成本 > 追回金额
