# IVF-PQ 深入

> 前篇：[IVF-PQ 概述](ivf-pq.md)

## IVF 深入

### K-means 聚类

优化目标：

$$\min \sum_{i=1}^{K} \sum_{x \in C_i} \|x - c_i\|^2$$

迭代：分配（每个向量归到最近 centroid）→ 更新（centroid = 簇内均值），直到收敛。

### 搜索过程

1. 计算 q 到 K 个 centroid 的距离 → O(K × d)
2. 选最近的 nprobe 个簇（典型 8~64）
3. 在候选簇的倒排列表中暴力计算 → O((N/K) × nprobe × d)

**精度损失的根源**：q 的真实最近邻如果落在第 nprobe+1 近的簇里就会漏掉。

### 参数 K 选择

- K 太小：簇太大，剪枝效果差
- K 太大：簇太小，nprobe 不变时容易漏真近邻
- 经验值：$K \approx \sqrt{N}$ 到 $4\sqrt{N}$，1M 向量约取 1000~4000 个簇

## PQ 深入

### 量化过程

d 维向量切成 m 段（每段 $d^* = d/m$ 维），每段独立量化到各自 codebook 中最近的码字：

```
原始: [0.1, 0.3, -0.2, 0.8, -0.5, 0.1, 0.7, -0.3]  (d=8, 32B)
切 m=4 段，每段 256 个码字（1 字节编码）:
  → [42, 187, 13, 201]  (4B, 压缩 8 倍)
```

每个子空间独立维护一个含 256 个码字的 codebook。

### ADC（Asymmetric Distance Computation）

搜索时**查询向量 q 不量化**，只量化数据库向量：

1. 预计算：对每个子空间 j，算 q 子向量与 codebook_j 全部 256 个码字的距离 → m 个长度为 256 的 lookup table
2. 对任意压缩向量：距离 = 各子空间查表值累加，只需 m 次查表 + m-1 次加法

$$\text{dist}(q, v_{compressed}) = \sum_{j=1}^{m} table_j[code_j]$$

| 方式 | 做法 | 精度 |
|------|------|------|
| SDC（对称） | q 也量化，码字间预计算 | 差 |
| ADC（非对称） | q 保持原始精度 | 好（默认） |

## IVF-PQ 完整流程

### 建索引

```
训练阶段:
  1. IVF: K-means → K 个 centroid + 倒排列表
  2. PQ:  每个子空间独立 K-means → m 个 codebook（各 256 码字）

对每个向量入库:
  1. 找最近 centroid → 归入对应倒排列表
  2. PQ 编码压缩 → 存 m 字节编码
```

IVF 和 PQ 训练独立，可用同一批训练数据。

### 搜索

```
1. q 与 K 个 centroid 算距离 → 取 nprobe 个最近簇
2. 对每个候选簇:
     a. 预计算 m 个 lookup table
     b. 遍历倒排列表，查表累加距离
3. 小顶堆维护 top-k
```

### 内存测算（1 亿条 128 维）

| 组件 | 大小 |
|------|------|
| 原始向量 | 51.2 GB |
| PQ 编码（m=64） | 6.4 GB |
| 向量 ID 列表 | 0.4 GB |
| Codebook | ~128 KB |
| **合计** | **~6.8 GB（压缩 7.5x）** |

### 调参指南

| 参数 | 增大效果 | 代价 |
|------|----------|------|
| nprobe | 精度↑ | 延迟↑ |
| m（PQ 段数） | 精度↑（子空间维度低→量化误差小） | 内存↑（每向量 m 字节） |
| K（IVF 簇数） | 精度↓（簇更小→易漏）但延迟↓ | 训练更长 |

nprobe 是查询时的参数，可以动态调整；m 和 K 是建索引时确定的。
