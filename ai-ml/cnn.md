# CNN（Convolutional Neural Network，卷积神经网络）

> 相关笔记：[VLM](vlm.md) | [感知机](transformer/perceptron.md)

## 为什么全连接不行

224×224×3 = 150528 像素 → 全连接第一层 1000 神经元 = 1.5 亿参数。更根本的问题：忽略空间关系（相邻像素构成边缘、形状、物体）。

## 三个核心操作

### 1. 局部感受野

3×3 卷积核每次只看 9 个像素，在整个图上滑动。

### 2. 权重共享

同一个 3×3 核（9 个参数）在图像所有位置复用。不管猫在左上角还是右下角，同一个核检测它。

→ 平移不变性：天然副产品。

### 3. 逐层抽象

```
浅层: 检测边缘、纹理、颜色
深层: 检测眼睛、鼻子、整张脸
```

## 典型结构

```
[224,224,3] → Conv(64×3×3) → ReLU → MaxPool → [112,112,64]
            → Conv(128×3×3) → ReLU → MaxPool → [56,56,128]
            → ... → [7,7,512] → Flatten → FC → Softmax
```

空间逐层缩小，通道逐层增多。

## 核心参数

| 参数 | 含义 | 典型值 |
|------|------|--------|
| kernel size | 卷积核大小 | 3×3 |
| stride | 步长 | 1 |
| padding | 边缘补零 | same |
| filters | 输出通道数 | 64, 128, 256... |

### Pooling

MaxPool 2×2 stride=2 → 空间减半，增大感受野，减少计算量。

### 感受野

深层像素对应原始图像的区域逐层线性增长：3×3 → 5×5 → 7×7...

## CNN → ViT → VLM

```
CNN (2012~2020): 卷积 + Pooling, 强归纳偏置, 平移不变, 需要数据少
    代表: ResNet, VGG, EfficientNet
ViT (2020~): Patch → Token → Transformer, 放弃局部先验, 需要海量数据
VLM (2023~): ViT + LLM → 能看图的大模型
```

CNN 的局部性和平移不变性是强归纳偏置——不妨理解为模型「天生知道平移不变性」，不需大量数据学。ViT 放弃偏置换灵活性，数据充足时上限更高。
