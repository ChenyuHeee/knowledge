# BVH（Bounding Volume Hierarchy，层次包围盒）

## 是什么

一种空间加速结构，最常见于光线追踪（Ray Tracing）。核心目的：在几百万三角形中快速找到光线击中了哪一个，从 O(N) 降到 O(log N)。

## 直觉

层层包裹：

```
根节点 (包住整个场景)
  ├── 左子树 (房间A)
  │     ├── 三角形1
  │     └── 三角形2
  └── 右子树 (房间B)
        ├── 三角形3
        └── 三角形4
```

光线先和大的盒子测交，不碰则整棵子树剪枝跳过。

## 结构

```python
class BVHNode:
    bbox: AABB          # 轴对齐包围盒
    left: BVHNode       # 左子
    right: BVHNode      # 右子
    triangles: List     # 叶节点才存三角形
```

## 构建（递归）

1. 取所有三角形，算包围盒
2. 沿最长轴分割（SAH 启发式找最优面，或中点 split）
3. 分两堆，递归建子 BVH
4. 三角形数 < 阈值（如 4）→ 叶节点，停止

## 遍历（搜索交点）

```
hit(ray, node):
    if ray 和 node.bbox 不相交: return     ← 剪枝，核心价值
    if node 是叶节点: 逐个检测三角形
    否则: 递归检查 left 和 right，返回最近交点
```

第一行的剪枝是 BVH 存在的全部意义。

## BVH vs KD-Tree

| | BVH | KD-Tree |
|------|-----|---------|
| 划分 | 按物体分 | 按空间分 |
| 包围盒 | 可重叠 | 不重叠 |
| 建树速度 | 更快 | 更慢 |
| 现代渲染器 | **主流** | 基本被取代 |

BVH 胜在物体空间划分不需要处理「一个三角形跨两个空间区域」的边界情况。
