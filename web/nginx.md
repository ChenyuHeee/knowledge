# Nginx

> 相关笔记：[Uvicorn](../python/uvicorn.md)

## 是什么

高性能 HTTP 服务器和反向代理。全球 ~35% 的活跃网站使用。

## 架构位置

```
用户 → Nginx (入口) → 反向代理转发 → 后端服务 (Uvicorn/Node.js/...)
                     → 静态文件直接返回
                     → 负载均衡到多个后端
```

## 核心能力

| 能力 | 说明 |
|------|------|
| 反向代理 | 公网请求转发到内网服务器 |
| 静态文件 | HTML/CSS/JS/图片直接返回 |
| 负载均衡 | 流量均匀打到多个后端 |
| SSL 终结 | 处理 HTTPS，后端走 HTTP |
| 限流 | 限制 IP/路径的并发数 |
| 缓存 | 缓存后端响应 |

## 为什么快：事件驱动

| | Apache | Nginx |
|------|--------|-------|
| 模型 | 每请求一进程/线程 | **单进程 + epoll** |
| 1000 并发 | 1000 进程 | 几个 worker |
| 内存 | 随并发线性增 | 几乎不变 |

有数据就处理，没数据就等。单 worker 同时监听数千连接。

## 与 Uvicorn 的关系

```
Nginx (80/443, 处理 HTTPS/限流/静态) → proxy_pass → Uvicorn (8000, 专注 Python)
```

各司其职——Nginx 挡流量，Uvicorn 跑逻辑。
